# 가렌 QWER 적용 및 검증

## 실행과 조작

npm install → npm start → http://127.0.0.1:3000 → 닉네임 → 방 만들기 → 밴픽 시작 → **가렌** → 선택 완료. 혼자 시작하면 기존 서버가 상대 AI를 추가합니다. 기존 빠른 연습 버튼에는 핸들러가 없어 방 만들기 흐름을 사용하세요.

우클릭 이동/대상 공격, A 공격 이동. Ctrl+Q/W/E/R 또는 HUD ▲로 스킬을 배웁니다. 기본 스킬은 1/3/5/7/9레벨에 각 랭크, R은 6/11/16레벨에 해금됩니다. 현재 게임의 시작값은 Q 1랭크와 스킬 포인트 1개입니다.

| 키 | 동작 |
|---|---|
| Q 결정타 | 둔화 해제, 이동 속도 증가, 다음 평타 강화 및 1.5초 침묵. 강화 달리기/내려찍기 원본 애니메이션 |
| W 용기 | 짧은 보호막·강인함, 일정 시간 피해 감소. 이동·E 중 사용 가능, 금빛 보호막 |
| E 심판 | 3초 동안 이동하며 회전 피해. 1초 후 E 재입력으로 종료. 원본 회전·검 궤적·소리 |
| R 데마시아의 정의 | 적 챔피언 위에 커서를 두고 R. HUD R 클릭 후 다음 좌클릭으로 대상 선택. 사거리400, 0.5초 시전 후 잃은 체력 비례 고정 피해 |

가렌은 마나를 사용하지 않습니다. 대상 없음/사거리 밖/미습득/쿨타임/침묵 등으로 서버가 거절하면 스킬 효과음·이펙트도 발생하지 않습니다. E 중 기본 공격은 멈추고, R 시전 중 이동은 잠깐 잠깁니다.

## 리소스와 구현 경계

로컬 설치본에서 모델·텍스처·8개 뼈대 애니메이션, 17개 이펙트 텍스처, 9개 Wwise 효과음 믹스를 추출했습니다. Q 이동/타격, E, R은 원본 클립입니다. 기본 스킨에는 W 전용 spell2 뼈대 클립이 없어 보호막을 현재 동작에 겹칩니다. 원본 파티클 실행 그래프/셰이더는 웹용 Three.js 레이어로 재구성했습니다. 사운드는 원본 이벤트의 결정적 변형 한 가지를 디코딩했으며 Wwise 전역 버스 처리는 재현하지 않았습니다. 사망 뼈대 애니메이션은 이번 범위에 없습니다.

GarenMechanics.js가 판정하고 garenSkill {playerId,key,phase,targetId,targetX,targetY,x,y,duration} 이벤트를 전송합니다. phase는 cast/hit/end입니다. player.garen 스냅샷의 Q/W/E/R 남은 시간으로 클라이언트가 상태를 보정합니다. garenModel.js, garenEffects.js, garenAudio.js가 재생하며 기존 음소거 버튼을 공유합니다.

가렌의 championId는 **garen**, 기존 검객은 **blademaster**입니다. 검객의 원래 마나·스탯·3회 공격 패시브·Q 돌진/W 회전베기/E 보호막/R 공중 띄우기·절차적 외형을 복원했습니다. 둘은 별도 선택 카드로 함께 픽할 수 있으며 이 분리 시점에는 11명이었으며, 이후 독립 야스오가 추가되어 현재는 12명입니다. 다음 경기에서 선택을 바꿔도 이전 모델이 남지 않도록 경기 시작 시 외형 상태를 정리합니다.

행동·쿨타임·범위 참고: [Riot Garen 소개](https://www.leagueoflegends.com/en-us/champions/garen/), [Data Dragon 16.21.1](https://ddragon.leagueoflegends.com/cdn/16.21.1/data/en_US/champion/Garen.json). 해당 데이터가 피해 공식의 실제 상수를 모두 제공하지 않아 아래 세부 수치는 명시적인 로컬 구현값입니다. 원본 시뮬레이션과 완전히 같다고 주장하지 않습니다.

- Q: 추가30/60/90/120/150+0.5AD, 이동 속도+35%를1/1.65/2.3/2.95/3.6초, 강화 평타 대기8초.
- W: 보호막65+랭크당20+추가체력18% 및 강인함60%를.75초. 물리·마법 피해30% 감소를2~5초. 처치마다 방어력/마저.2, 최대30.
- E: 기본7회+추가 공속25%마다1회, 회당4/8/12/16/20+레벨 보정0~8.2+0.32~0.40AD. 최근접 적25% 추가, 6회 적중 시 방어력25% 감소6초. 범위325. 쿨타임은 시전부터 시작하고 조기 종료 시 환급하지 않습니다.
- R: 150/300/450+잃은 체력25/30/35% 고정 피해.
- 인내: 챔피언·포탑·에픽 몬스터 피해 후8초, 이후 레벨 비례 최대체력1.5~11.6%/5초 회복.
